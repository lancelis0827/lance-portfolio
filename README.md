# Lance Portfolio

My personal portfolio website and a long-term record of my growth as a software developer.

## Purpose

This project is built to:

- Introduce who I am as a developer.
- Showcase the projects I build.
- Document my growth and improving skills.
- Give me practical experience with web development, Linux, Git, security, and cloud deployment.
- Continue evolving throughout my career.

## Technology Stack

- HTML
- CSS
- JavaScript
- Git and GitHub
- WSL2 Ubuntu 24.04

## Current Features

- Semantic HTML structure
- Responsive layout
- Light and dark themes
- System theme detection
- Persistent theme preference
- Keyboard-accessible navigation and controls
- Responsive navigation
- Project, skills, and contact sections
